# Backend speech-to-text (the /api/stt WebSocket). Imported lazily by
# demo/server/stt_ws.py, only when a client connects to the STT socket; the
# backend imports fine without these and the frontend falls back to the browser
# Web Speech API. Install to enable STT:
#   - websockets : client to the customer's streaming Zipformer STT server
#                  (ws://.../ws/stream). Present transitively via uvicorn[standard],
#                  but declared here because the STT path imports it directly.
#   - torch      : runs the Silero VAD that gates utterances (heavy; this is the
#                  dep the trimmed deliverable dropped). The Silero model is
#                  fetched on first use via torch.hub (snakers4/silero-vad) and
#                  cached under ~/.cache/torch/hub.
# numpy (declared above) does the server-side 16 kHz→8 kHz resample for Zipformer.
websockets
torch

# OPTIONAL — Chirp 3 STT (Speech-to-Text V2). No longer used by the demo (the STT

# services.speech.stt. Install only if you run that probe.
google-cloud-speech
